# Muhammad Bilal — QA Engineer & Automation Specialist Portfolio

A modern, high-precision personal portfolio engineered with **Next.js (App Router)**, **TypeScript**, and **Tailwind CSS**. Designed specifically to showcase Muhammad Bilal's dual background: **1 Year Professional Software Quality Assurance (QA)** and **1 Year Full-Stack MERN Stack Development**.

---

## 🌟 Unique Design Concept: "The QA Command Center & Interactive Test Lab"

Unlike traditional generic developer templates, this portfolio is built around a **QA Command Center** aesthetic with real interactive testing capabilities:

1. **Top Telemetry & QA Self-Test**:
   - Live system health indicator (`SYSTEM: OPTIMAL`).
   - "Run QA Self-Test" button in the header that triggers live assertion diagnostics and celebratory confetti.

2. **The Dual-Lens Advantage ("Developer-Turned-QA")**:
   - Highlights why having 1 year of MERN stack experience makes Bilal test deeper: understanding React state hooks, DOM lifecycles, REST API payloads, and asynchronous race conditions.

3. **Interactive QA Test Lab & Simulator**:
   - **Playwright Test Runner Simulator**: Visitors can select test suites (`recruiter-signup-flow.spec.ts`, `contract-business-rules.spec.ts`, `staging-payin-payout-workflow.spec.ts`) and trigger headless test execution with real-time logs and pass badges.
   - **Postman REST API Inspector**: Interactive API tester allowing visitors to toggle Positive, Negative, and Edge-Case requests, inspect HTTP status codes (200, 401, 422, etc.), headers, payloads, and view automated test assertions.
   - **Jira Defect Triage & Retest Explorer**: Real reproduction logs based on Bilal's work at Hireboard (e.g. `HB-1402`, `HB-1289`, `HB-1154`), including steps to reproduce, expected vs actual behavior, and regression verification status.
   - **Hireboard Multi-Portal Coverage Matrix**: Comprehensive breakdown of the 3 portals tested: **Admin Dashboard**, **Recruiter Portal**, and **Talent Portal**.

4. **Experience & Skills Matrix**:
   - Interactive search and filterable skill categories (Testing Core, API & Tools, Automation, MERN Development, QA Practices).
   - Rich timeline with deep-dive achievements for **Hireboard** (Remote QA Engineer) and **Vonza** (Remote MERN Stack Developer).

5. **Education & Certifications**:
   - BSCS at Sindh Madressatul Islam University (SMIU) & Intermediate at Foreman College.
   - ISTQB Software Testing Course (Udemy, company-sponsored), Burraq Tech SQA Course, and Saylani Web Development Course.

6. **ATS-Ready Resume Modal**:
   - Clean, formatted modal view of the complete resume with one-click **"Print / Save PDF"** capability.

7. **Contact Hub**:
   - One-click copy for email (`bilalsqa10@gmail.com`) and phone (`+92 311 3254286`), direct WhatsApp and LinkedIn links, and an interactive message inquiry form with ticket reference generation.

## 🚀 How to Run Locally

### Prerequisites
- Node.js (v18+)
- npm or pnpm

### Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Open in browser
http://localhost:3000
```

### Production Build

```bash
npm run build
npm start
```
